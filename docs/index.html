FAQ

常见问题

为什么只支持这几台设备？

按产品定位只覆盖自用的三台外设，新设备再补，不提前铺摊子。接入新 BLE 设备只需实现 IBatteryReader 接口。

托盘图标不显示 / 卡片弹不出来？

确认 ChargeDock.exe 所在目录可正常写入。若从受限目录（如某些沙箱目录）运行，托盘线程可能失败，建议放到 %LOCALAPPDATA%\Programs\ChargeDock\。

为什么键盘没有电量？

K820 固件不上报电量，属设备限制，读不到就不显示，不会展示假数据。

支持浅色模式吗？

支持。设置页 → 外观 → 浅色 / 深色 / 跟随系统，默认跟随系统，切换时卡片会淡出淡入过渡。

卡片的玻璃是真模糊吗？

不是系统级亚克力，而是自绘的半透明玻璃底。这样整张卡片（含背景）可以一起做 GPU 滑动，动效更顺滑、圆角也更可控。
