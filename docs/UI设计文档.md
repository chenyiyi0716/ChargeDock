# ChargeDock UI 设计文档

> 版本：v1 · 方向：玻璃拟态（Glassmorphism）· 状态：已定稿

## 1. 设计方向

**玻璃拟态（Glassmorphism）**：半透明毛玻璃 + 柔和弥散阴影，通透轻盈，能自然融入任意桌面壁纸。提供浅色 / 深色两套主题。

本设计由四部分组成：**主卡片**、**设置页**、**托盘图标（环形仪表）**、**托盘右键菜单（玻璃风格）**。完整定稿见 [ui-design-v2.html](ui-design-v2.html)。

## 2. 整体风格

- 大圆角（约 22px）、毛玻璃模糊、柔和描边
- 字体：Segoe UI Variable / 系统默认无衬线
- 用色克制：主体为中性灰，仅用绿 / 黄 / 红表达电量状态

## 3. 主卡片结构

自上而下：

- **标题栏**：左侧「ChargeDock」文字（无图标）；右侧「N 已连接」状态点 + 齿轮（设置入口）。
- **设备列表**：鼠标、键盘、耳机，每行 = 图标 + 名称/连接方式 + 电量条 + 百分比。

### 设备行

- 图标：柔和底色的圆角方块 + 线形图标（鼠标 / 键盘 / 耳机）
- 名称 + 副标（设备类型 · 连接方式）
- 电量条：圆角进度条
- 百分比：等宽数字，右对齐

### 耳机子行

耳机下拆分 **L / R / 仓** 三行，各自独立显示电量；未连接的单耳 / 充电仓不显示。

## 4. 电量颜色规则

| 电量 | 颜色 |
| --- | --- |
| ≥ 50% | 绿色 |
| 20% – 50% | 黄色 |
| ≤ 20% | 红色（低电量） |

## 5. 低电量表现

鼠标 / 键盘电量 ≤ 15% 时：卡片中该设备**变色** + **弹窗提醒**（阈值可在设置页调整）。耳机不做低电量提醒。

## 6. 设置页

**入口**：主卡片右上角齿轮图标。

分组内容：

- **通用**：开机自启（开关）、刷新间隔（30s / 60s / 5m 分段选择）
- **低电量提醒（鼠标 / 键盘）**：启用开关、提醒阈值（步进器，默认 15%）、弹窗提醒、卡片变色
- **外观**：主题（浅色 / 深色 / 跟随系统）
- **关于**：版本号、检查更新

### 控件风格

- 开关：iOS 式 toggle
- 分段选择：segmented control
- 步进器：− / ＋ 步进

## 7. 主题

浅色 + 深色各一套，均含主卡片与设置页；支持「跟随系统」。

## 8. 托盘图标

托盘图标固定采用 **环形仪表** 样式（环形进度 + 中心百分比），不提供样式切换。

- 环形：圆环进度，弧长表示电量；中心显示当前电量（如 86%）
- 颜色：随电量变化（绿 / 黄 / 红）
- 尺寸：逻辑尺寸 16×16，实际提供 16/24/32/48 多倍率以适配高 DPI

设计稿见 [tray-icons-v1.html](tray-icons-v1.html)（圆环仪表样式）。

## 9. 托盘右键菜单

替换系统原生菜单，采用与卡片一致的玻璃风格。菜单项：

- 显示电量 / 隐藏卡片
- 立即刷新
- 设置…
- 开机自启（开关）
- 关于 ChargeDock
- 退出（危险色）

最终采用 **A 图标分组式（无状态头）**：带图标、分组分隔、内置开关；B 极简文字式保留为备选。设计稿见 [tray-menu.html](tray-menu.html)。
